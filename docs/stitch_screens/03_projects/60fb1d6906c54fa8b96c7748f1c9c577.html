RFC: Deprecating Legacy Session Cookies in favor of OIDC JWT Claims

With the upcoming edge distribution across three geographic regions, centralized stateful Redis sessions introduce a roundtrip penalty of ~78ms. We propose transitioning auth validation to asymmetric JWT tokens validated locally via public JWKS sets.

The proposed authorization header payload structure is validated at API gateway ingress:
