description Detailed Specification & Replication Steps

Starting at roughly 08:24 AM UTC, synthetic monitors alerted to elevated tail latency (p99 spiked from 18ms to 4,820ms) across all inbound OAuth2 bearer token validations routed through auth-proxy-us-east-1.

Client requests exhibit HTTP 504 Gateway Timeouts intermittently. Initial threadpool inspections point to connection exhaustion in the downstream Redis session cache cluster following certificate auto-renewal.

terminal Steps to Reproduce
  1. Dispatch curl payload simulating concurrent user handshake: curl -X POST https://api.us-east.tronix365.internal/v2/auth/verify -H "Authorization: Bearer test_token"
  2. Observe response timeline stalls between TLS termination and upstream socket handoff.
  3. Envoy router metrics log downstream resets with flag DC (Downstream Connection Termination).
